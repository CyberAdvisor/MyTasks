# Security

How My Tasks protects your list is described at [mytasks.fyi/security](https://mytasks.fyi/security/).

## Reporting a vulnerability

Please report security problems privately, through GitHub's [private vulnerability reporting](https://github.com/CyberAdvisor/MyTasks/security/advisories/new), not in a public issue. Include what you found and how to reproduce it.

Only the current version, at [mytasks.fyi/app](https://mytasks.fyi/app/), is supported.
