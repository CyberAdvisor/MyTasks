Import from other apps

My Tasks imports tasks from a CSV file in its own format, described on this page. It also reads Todoist’s own export files. For other apps, you can make the file yourself, in Numbers, Excel or Google Sheets, or have the script for Things 3 write it for you. Importing the files other task apps export is coming.

What converts now, and what’s coming

  • Now: Todoist’s own export files (From Todoist); a file in this page’s format that you make yourself (The columns); or one the script for Things 3 writes (From Things 3).
  • Coming: importing the files OmniFocus exports, and Microsoft To Do’s once Microsoft releases its export.

How import works

  • Import… in Settings › Import From Other Apps reads the file, shows what it holds (“120 tasks, 8 projects and 3 areas”) and adds it all when you choose Import. One Undo (Cmd+Z, or Undo on iPhone and iPad) takes it all back.
  • It adds to what you have and never replaces it. An area, project or tag with the same name as one you already have is added to; anything new is created.
  • If any row has a problem, nothing is imported, and the message names the row so you can fix it.
  • Import counts toward the 5,000-task limit, and is refused if it would go past it.
  • An archive file from Settings › Archive is in this format, so importing it brings its items back, completed, to Completed.

The template and a sample

  • mytasks-import-template.csv: the header row only, ready to fill in.
  • mytasks-import-sample.csv: two areas, a project with headings, a task with a checklist, four kinds of repeating task and a repeating project.

Save the file as CSV in UTF-8, with the header row first. Columns can be in any order, and any column can be left out or left blank: a blank takes the app’s usual default. Dates are written YYYY-MM-DD, such as 2026-12-08.

The columns

Each row is one item, and its type says which: area, project, heading, task or checklist (one checklist item).

A few rules make a file easy to type by hand:

  • Checklist rows belong to the task row just above them, unless they have a parent_id.
  • Names are matched to your existing areas, projects and tags without regard to capitals.
  • Order: tasks, headings and checklist items keep the order they have in the file. With ids, rows can come in any order.
  • A repeating task is imported as the repeating task itself; My Tasks makes its copies on their dates, as for one you set up in the app.
  • A repeating project is imported as its template, always as a new project. Its tasks, headings and checklists are what each copy will hold, so a task in it takes no start date, deadline or repeat of its own. If its first date is today or earlier, today’s copy is made as it comes in.

From Todoist

Import… reads the CSV file Todoist exports for a project (its ⋯ menu, Import & export › Export to CSV, with Use relative dates unticked), so you don’t need to change it. Each file becomes a project; you can pick several at once. Dates and repeats are read in English only. The steps, what comes across and the limits are in the Guide’s Importing from Todoist.

From Things 3

A small script that you run on your Mac reads Things 3 and writes this file for you: your areas, projects, headings, open tasks with their checklists, tags, notes, dates, deadlines, and repeating tasks and projects. Completed and trashed items aren’t included, and Things tags come across as tags, with one exception: Things has no priorities, so a task’s tag named P1 to P5 becomes its priority in My Tasks instead of a tag (the highest one, if it has several). A project keeps such a tag as a tag, since only tasks have priorities, and so does a tag inside another tag. It only reads Things; it never changes anything there, and nothing leaves your Mac.

  1. Open Terminal (in Applications › Utilities).
  2. Paste these two lines and press Return. The first downloads the script (read it on GitHub) into your Downloads folder; the second runs it there. 
    cd ~/Downloads && curl -fsSLO https://raw.githubusercontent.com/CyberAdvisor/MyTasks/main/helper/things_export.py
python3 things_export.py
  3. If macOS asks whether Terminal may access data from other apps, click Allow. If your Mac offers to install the command line developer tools instead, install them (they include Python) and run the second line again.
  4. The script says how many items it wrote to Things export with today’s date, in your Downloads folder. Repeating to-dos and projects come across as the repeating item itself; the copies Things has already made are left out, as My Tasks makes its own. A copy that’s still open, such as one in Today, sets where the repeat starts, so My Tasks makes that copy again when you import. Tags you added to that copy in Things come across too.
  5. In My Tasks, open Settings › Import From Other Apps › Import…, choose that file, check the preview, and click Import.

To bring in only part of it, open the file in Numbers or Excel, delete the rows you don’t want, and save it as CSV first. Each task row keeps its Things id in the id column, which links its checklist rows to it.
