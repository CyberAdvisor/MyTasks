Before you rely on it

My Tasks is ready for use, within its limitations. Please read these before you put anything important in it:

  • You need a GitHub account and a personal access token. Your tasks are kept, encrypted, in a secret gist in your account. (A gist is a file stored in your GitHub account. A secret gist isn't listed or searchable, but anyone with its web address can open it, which is why My Tasks encrypts it.)
  • A forgotten passphrase can't be recovered. Without it, your tasks can't be decrypted.
  • If you edit the same task on two devices before they sync, the later edit wins and the other is lost.
  • No reminders or notifications, no widgets, no Siri.
  • Android is best effort.

Common questions

Is My Tasks really free?

Yes. Every feature, on every device, at no cost: there's no paid tier or trial. It's open source under the MIT licence. If it helps you, you can support it on Ko-fi, but you don't have to.

Is my data safe?

Your tasks are encrypted on your device, with your passphrase (AES-256-GCM), before they're sent to a secret gist in your own GitHub account. GitHub, or anyone else who reaches the gist, sees only scrambled data, and only your GitHub account can change it. Your passphrase is never stored or sent anywhere, so it can't be recovered: if you lose it and no device is still connected, your tasks in the gist can't be decrypted. Write it down somewhere safe. For a copy of your own, use Save Backup in Settings › Backup to save all your tasks as a file on your computer. The file isn't encrypted, so keep it somewhere private. How the encryption works.

What happens if this project is abandoned?

My Tasks has no server or account of its own, so your tasks don't depend on it. The website and app are plain static files, open source under the MIT licence. Anyone can clone the repository from GitHub and publish it on GitHub Pages or any other static hosting service, such as Cloudflare Pages or Netlify, and keep using it with the same gist for as long as they like. Your own copy explains how. Your tasks stay in your gist and your backups either way.

Why do I need a GitHub account?

My Tasks has no server of its own. Your tasks are kept in a secret gist in your GitHub account, which is how your devices stay in step. How to connect it.

Can I take my data with me?

Yes. Save Backup in Settings › Backup downloads all your tasks as a file whenever you like, Archive saves old completed tasks to a CSV file, and the gist is in your own account. Back up and restore.

Does it work offline?

Yes. Installed, My Tasks opens and works with no connection, and your changes sync when you're back online.

Can I import tasks from another app?

Yes. Import… in Settings adds tasks from a CSV file to what you have, after showing you what it holds. A script for your Mac writes that file from Things 3. Import from other apps.

Does it have reminders?

No. A web app without a server can't send reminders or notifications. For a task that needs an alert at a set time, add a reminder for it in your device's reminders app, such as Apple Reminders. What a web app can't do.
